# KodiSalama APK

Android app ya KodiSalama - mfumo wa usimamizi wa kod za nyumba kwa wamiliki wa nyumba (landlords) Tanzania.

## Vipengele

- **Muhtasari wa Wapangaji** - Ona idadi ya wapangaji active na vyumba
- **Kodi Zilizochelewa** - Notification ya kodi ambazo hazijalipwa
- **Malipo Yajayo** - Tarehe za malipo yanayokuja
- **Wapangaji Bila Chumba** - Orodha ya wapangaji wasiopangwa
- **Daily Notifications** - Muhtasari kila siku saa 08:00 (hata app ikiwa closed)

1. Download APK kutoka [Releases](https://github.com/galaxymushizo-netizen/kodisalama-apk/releases)

3. Ruhusu "Install from unknown sources" kama inahitajika
4. Install na ufungue app
